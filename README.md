# amirabroun.github.io

Personal résumé / portfolio — a Nuxt one-pager, static-generated and deployed to
GitHub Pages via Actions.

- Dev: `npm run dev`
- Build (static): `npm run generate` → `.output/public`
- Deploy: push to `main` (workflow in `.github/workflows/deploy.yml`)

Live: https://amirabroun.github.io
